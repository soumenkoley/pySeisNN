# Single-body-wave Newtonian noise for a cuboidal cavity

This chapter documents `getCubNNSingleBody.ipynb`. The notebook calculates the
Newtonian acceleration generated by one prescribed plane body wave in a
homogeneous medium containing a cuboidal cavity. It validates the numerical
bulk, truncation-surface, and total NN terms against semi-analytic finite-box
expressions from `modules/bodyPSNN.py`.

The workflow closely follows `getSphNNSingleBody.ipynb`. The important changes
are the rectangular cavity geometry, face-dependent local refinement, and the
semi-analytic cuboid response.

## What the example demonstrates

The notebook shows how to:

- configure an elongated cuboidal cavity;
- place a test mass at its centre;
- prescribe one deterministic P, SV, or SH plane wave;
- construct a locally refined grid around six planar cavity faces;
- calculate volume and outer-boundary NN terms;
- compare numerical and semi-analytic finite-box responses; and
- check the low-frequency geometric response using a cuboid solid-angle
  factor.

The supplied case is a homogeneous half-space calculation, although the
notebook and semi-analytic functions also contain full-space branches.

## Required files

The notebook expects:

- `configParseHalfSpaceBodyHomo.ini` from the cuboid body-wave tutorial;
- `SingleCubCavityHalfSpace.ini`;
- the modules under `modules/`; and
- writable paths specified in the main configuration.

Update the absolute paths in both notebook cells when using another

configFile = "/path/to/configParseHalfSpaceBodyHomo.ini"

## Tutorial medium and domain

The supplied configuration uses a homogeneous medium with:

- `vp = 4000 m/s`;
- `vs = 2000 m/s`;
- `rho = 2465 kg/m^3`; and
- identical properties in the finite layer and bottom half-space.

The numerical domain extends from -3000 to +3000 m in x and y and from the
free surface to 3000 m depth. The frequency band is 2.0–7.9 Hz, and the
background integration grid uses six points per minimum relevant wavelength.

The notebook selects half-space treatment with:

```python
fullSpace = False
```

When adapting the notebook to a full space, change this variable consistently
in both cells and use matching main and cavity configurations.

## Cuboidal cavity

The cavity file defines:

```ini
[CavityA]
shape = cuboid
xC = 0.0
yC = 0.0
zC = 250.0
length = 400.0
breadth = 20.0
height = 20.0
angleDeg = 0.0
xRefineFactor = 4.0
yRefineFactor = 10.0
zRefineFactor = 8.0
```

The full cavity dimensions are therefore:

- 400 m along its local x/length axis;
- 20 m along its local y/breadth axis; and
- 20 m vertically.

Its centre is at `(0, 0, 250 m depth)`. `angleDeg = 0` aligns its local length
axis with global x. A positive angle would rotate the cavity anticlockwise
about z.

The numerical geometry supports rotated cuboids. The semi-analytic comparison
cell, however, constructs axis-aligned `cavity_bounds` from half-lengths
`a`, `b`, and `c`; it does not apply `angleDeg`. The supplied validation must
therefore remain unrotated unless the analytic geometry is extended.

## Test mass

The notebook selects only `itm_ac`:

```python
itmAll = np.vstack((itmACUse,))
```

The supplied position is `(0, 0, 250 m depth)`, exactly at the cuboid centre.
The positive configured depth is converted internally to `z = -250 m`.

The centred placement is assumed by the solid-angle check and is the simplest
configuration for comparing numerical and semi-analytic results. The analytic
functions can accept a shifted test-mass coordinate, but any shift must be
applied consistently in both numerical and comparison geometry.

## Body-wave selection

The wave type is selected near the beginning of the simulation cell:

```python
wType = "Px"
```

Supported cases are:

| `wType` | Propagation | Polarization/displacement | Compared component |
| --- | --- | --- | --- |
| `Px` | +x | P displacement along +x | x |
| `Pz` | +z | P displacement along +z | z |
| `SHx` | +x | SH displacement along +y | y |
| `SHy` | +y | SH displacement along +x | x |
| `SVxz` | +x | SV displacement along +z | z |

`simDisp.genBodySrc` initially creates random metadata, but the notebook
overwrites it with one unit-amplitude, zero-phase plane wave. The unused wave
family remains as a zero-amplitude dummy entry to preserve the expected data
structure.

The final `else` branch implements `SVxz`; use the documented strings exactly,
because any unrecognized value also enters that branch.

## Face-dependent cavity refinement

The background grid spacing is calculated from the minimum relevant
wavelength. The notebook then associates the test mass with its cavity and
computes refinement widths using:

```python
etaUse = 0.5
wallRefineWidthAll = NNGeometryNN.getRefineWidths(
    tmInCavity,
    allCavities,
    hBGAll,
    eta=etaUse,
    minRefine=20.0,
)
```

For a cuboid, the current geometry code supports separate refinement
extensions outside the local `xMin`, `xMax`, `yMin`, `yMax`, `zMin`, and
`zMax` faces. It expands the cavity in local coordinates, rotates the expanded
horizontal rectangle into the global coordinate system, and constructs the
smallest global axis-aligned refinement box containing it. The vertical range
is clipped to the computational domain.

The `xRefineFactor`, `yRefineFactor`, and `zRefineFactor` fields remain part of
the cavity-file format, but the current notebook obtains its effective
wall-refinement widths dynamically from `getRefineWidths`. The printed
`wallRefineWidthAll` values are the relevant quantities to record for this
run.

## Reference displacement

For the selected deterministic body wave, displacement is evaluated at the
surface and cavity depth:

```python
zList = [0.0, cavDepthUse]
simDisp.getSurfDeepBodyDispPerRea(...)
```

The result is saved as `surfDeepDispRea0.npz`. It is available for later
normalization or scaling, although the semi-analytic comparison cell directly
uses the prescribed unit displacement `xi0 = 1.0`.

## Numerical NN integration

The medium is partitioned into layers and blocks around the refined cuboid.
For every block, the notebook evaluates:

- the displaced material volume;
- vertical outer truncation surfaces; and
- horizontal interfaces and outer horizontal surfaces.

The accumulated arrays have shape `(n_frequency, 3, 1)`:

| Array | Meaning |
| --- | --- |
| `IBlockTot` | Bulk contribution of the rock volume outside the cavity. |
| `IVertFaceTot` | Vertical outer-boundary contribution. |
| `IHorFaceTot` | Horizontal-interface and horizontal-boundary contribution. |
| `ITot` | Total response, `IBlockTot - IVertFaceTot - IHorFaceTot`. |

All three contributions are multiplied by Newton's gravitational constant
before the total is assembled.

## Output filename

The result filename encodes the realization, refinement parameter, wave type,
and cavity length:

```text
NNFullRea<rea>Eta<etaUse><wType>Len<length>.npz
```

For the supplied case:

```text
NNFullRea0Eta0.5PxLen400.0.npz
```

The file contains `IBlockTot`, `IVertFaceTot`, `IHorFaceTot`, `ITot`, and
`freqOut`. The second cell must use identical `etaUse`, `wType`, and `lenCav`
values to load the correct result.

## Semi-analytic finite-box model

The comparison cell represents the domain with:

```python
L = 3000.0
outer_bounds = (-L, L, -L, L, -L, 0)
```

for the half-space case. It defines cavity half-dimensions:

```python
a = 200.0
b = 10.0
c = 10.0
```

which correspond to the full `400 × 20 × 20 m` cavity in the INI file.

Depending on `wType`, the cell calls one of:

- `P_x_all_components_shifted`;
- `P_z_all_components_shifted`;
- `SH_y_x_all_components_shifted`;
- `SH_x_y_all_components_shifted`; or
- `SV_x_z_all_components_shifted`.

Each function integrates the analytic plane-wave response of the finite outer
box, subtracts the removed cuboid volume, evaluates the appropriate outer
surface term, and returns:

```text
H_bulk, H_vert, H_hor, H_total
```

The acceleration response for unit displacement is:

```python
A = G * rho * xi0 * H
```

with `xi0 = 1.0`.

## Comparison plots

The three panels compare:

1. numerical and semi-analytic bulk contributions;
2. the relevant vertical or horizontal boundary term; and
3. numerical and semi-analytic total acceleration.

For `Px`, `SHx`, and `SHy`, the middle panel compares `IVertFaceTot`. For `Pz`
and `SVxz`, it compares `IHorFaceTot`.

The middle-panel title is currently hard-coded as “Horizontal surface
contribution” even in cases that plot the vertical contribution. Interpret the
curves using the selected branch and labels, or generate the title from
`wType`.

The final plot shows the absolute total-response error:

```python
errOut = np.abs(
    A_total[:, compPlot] - Itot[:, compPlot, 0]
)
```

## Cuboid solid-angle check

For the x-directed response of a centred rectangular cavity, the comparison
cell evaluates:

```python
Tx = 8 * np.arctan(
    (b * c) / (a * np.sqrt(a*a + b*b + c*c))
)
```

`Tx` is a geometric solid-angle factor associated with the pair of cavity
faces normal to x. The notebook prints:

- `Tx`;
- `G * rho * Tx`;
- the first numerical total divided by `G * rho`; and
- the first semi-analytic total divided by `G * rho`.

This provides an additional low-frequency geometric check for the default
`Px` case. The expression shown is specific to the x-directed response and the
centred, axis-aligned cuboid.

## Running the example

1. Select matching half-space or full-space main and cavity configurations.
2. Update all machine-specific paths.
3. Verify that the medium is homogeneous and `if_body = True`.
4. Keep the cavity unrotated for the present semi-analytic comparison.
5. Select `wType` in the simulation cell.
6. Set `fullSpace` consistently in both cells.
7. Run the first cell and confirm that the expected `.npz` result is created.
8. Copy the same `wType`, `etaUse`, cavity length, dimensions, depth, and domain
   size into the comparison cell.
9. Run the comparison and inspect bulk, boundary, total, and absolute-error
   plots.
10. For `Px`, inspect the printed solid-angle consistency values.
11. Repeat with finer grids and modified refinement widths to establish
    convergence.

## Essential consistency checks

Before accepting the comparison, verify that:

- `length = 2*a`, `breadth = 2*b`, and `height = 2*c`;
- the numerical and semi-analytic cavity centres are identical;
- the selected test mass is at the intended location;
- `angleDeg = 0` for the current axis-aligned analytic comparison;
- `L` matches the numerical domain half-width;
- the half-space/full-space bounds match `fullSpace`;
- `wType`, `etaUse`, and output filename agree between cells;
- the correct acceleration component is selected;
- the middle comparison uses the appropriate vertical or horizontal term; and
- the grid and wall refinement are numerically converged.

## Scope and limitations

This is a controlled, unit-amplitude plane-wave validation. It does not model
a stochastic seismic field, a layered medium, a rotated-cuboid analytic
response, or multiple cavities. `getCubNNStochBody.ipynb` extends the cuboid
geometry to a stochastic P/S-wave ensemble.
