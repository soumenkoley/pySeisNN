# Tutorial configuration files

This directory contains the INI files used by the pySeisNN tutorial
notebooks. They preserve the examples' physical and numerical parameters, but
their `[paths]` sections contain machine-specific absolute paths and must be
adapted before use on another system.

See the [distributed configuration guide](../docs/distributed_configurations.md)
for the catalogue, notebook mapping, setup procedure, path requirements, and
safety notes. See the
[complete configuration reference](../docs/configuration_complete.md) for the
meaning and units of individual options.
